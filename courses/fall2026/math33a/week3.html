Math 33A Week 3: Determinants

Determinants are a bit tricky to discuss in a first linear algebra course, so we will just talk about how to compute them and some properties.

Consider an n×nn\times nn×n matrix AAA. Geometrically, we can imagine that AAA transforms the unit cube (which has "volume" 1) into a "parallelpiped" determiend by the columns of AAA. The determinant is signed "volume" of this "parallelpiped", or rather the signed "volume"-scaling factor of a matrix.

Thus intuitively, we should have det⁡(In)=1\det(I_n)=1det(In​)=1 and more generally:

Determinant of triangular matrices

We say a matrix is triangular if all its values above (or below) the diagonal are 0. If AAA is triangular, then det⁡(A)=a11⋯ann,\det(A)= a_{11}\cdots a_{nn},det(A)=a11​⋯ann​,
which is the product of the diagonal entries of AAA.

If we want to compute the determinant of a general matrix AAA, then we should try to make it triangular (via Gaussian elimination). So we need to know how the row operations in Gaussian elimination affect the determinant.

Row operations and determinants.
  1. Row swap: if we swap two rows of a matrix, then the determinant changes by a factor of −1-1−1. More specifically,det⁡(swap two rows of A)=−1det⁡(A)\det(\text{swap two rows of } A)= -1\det(A)det(swap two rows of A)=−1det(A)Geometrically, swapping rows reflects the transformed unit cube across some hyperplane (preserves volume, changes sign).
  2. Adding a multiple of one row to another row: if we do a row operation like Rj←Rj+cRiR_j \leftarrow R_j + cR_iRj​←Rj​+cRi​, then the determinant doesn't change. More specifically,det⁡(add multiple of row to another A)=det⁡(A)\det(\text{add multiple of row to another } A)= \det(A)det(add multiple of row to another A)=det(A)Geometrically, we are shearing the transformed unit cube (preserves volume and sign).
  3. Scaling a row: if we scale a row by a scalar kkk, then the determinant gets scaled by kkk. More specifically, det⁡(scale row of A by k)=kdet⁡(A)\det(\text{scale row of } A \text{ by } k) = k\det(A)det(scale row of A by k)=kdet(A)Geometrically, we are stretching (and possibly reflecting) the transformed unit cube in one direction which scales the volume with the same proportion and possibly switches the sign.

These three facts give us a way to compute the determinant of a matrix from its rref⁡(A)\operatorname{rref}(A)rref(A). In particular:

Determinant and RREF

Suppose in the process of computing rref⁡(A)\operatorname{rref}(A)rref(A), we do sss row swaps and rrr (nonzero) row scalings k1,…,krk_1,\dots, k_rk1​,…,kr​. Then we have that
det⁡(rref⁡(A))=(−1)sk1⋯krdet⁡(A)\det(\operatorname{rref}(A))= (-1)^sk_1\cdots k_r \det(A)det(rref(A))=(−1)sk1​⋯kr​det(A)or ratherdet⁡(A)=1(−1)sk1⋯krdet⁡(rref⁡(A))\det(A) = \frac{1}{(-1)^sk_1\cdots k_r}\det(\operatorname{rref}(A))det(A)=(−1)sk1​⋯kr​1​det(rref(A))

Other conventions

The textbook will state that
det⁡(A)=(−1)sk1⋯krdet⁡(rref⁡(A))\det(A)= (-1)^sk_1\cdots k_r \det(\operatorname{rref}(A))det(A)=(−1)sk1​⋯kr​det(rref(A))
This is true when in the process of Gaussian elimination, we divded rows by k1,…krk_1,\dots k_rk1​,…kr​. Be careful that you know if you are dividing rows or multiplying rows!

We have some easy consequences of this fact:

Invertibility and determinant

AAA is invertible if and only if rref⁡(A)=In\operatorname{rref}(A)=I_nrref(A)=In​ if and only if det⁡(rref⁡(A))=1\det(\operatorname{rref}(A))=1det(rref(A))=1 if and only if det⁡(A)≠0\det(A)\neq 0det(A)=0.

If AAA has inverse A−1A^{-1}A−1, then det⁡(A−1)=1det⁡(A)\det(A^{-1})= \frac{1}{\det(A)}det(A−1)=det(A)1​

Computing Determinant with Cofactor Expansion

Let AAA be some n×nn\times nn×n matrix. The i,ji,ji,jth cofactor of AAA is Cij=(−1)i+jdet⁡(A without ith row and jth column)C_{ij}= ({-1})^{i+j}\det(A \text{ without $i$th row and $j$th column})Cij​=(−1)i+jdet(A without ith row and jth column)Then for any row iii, we havedet⁡(A)=∑j=1nAijCij\det(A) = \sum_{j=1}^n A_{ij}C_{ij}det(A)=j=1∑n​Aij​Cij​ and for any row jjj, we have det⁡(A)=∑i=1nAijCij\det(A) = \sum_{i=1}^n A_{ij}C_{ij}det(A)=i=1∑n​Aij​Cij​

When to use Cofactor Expansion?

Notice that if a row or column of AAA has a lot of zeros, then many of the terms in the cofactor expansion will be 0, so it makes the determinant calculation faster.
