Math 33A Week 6: Bases of Linear Subspaces

Linear subspaces

A linear subspace VVV of Rn\R^nRn is a non-empty collection of vectors in Rn\R^nRn such that

  1. if x⃗,y⃗\vec{x},\vec{y}x,y​ are in VVV, then x⃗+y⃗\vec{x}+\vec{y}x+y​ is in VVV
  2. if x⃗\vec{x}x is in VVV, then kx⃗k\vec{x}kx is in VVV for any scalar kkk.

So in linear subspaces we can do vector addition and scalar multiplication.

Examples of linear subspaces
  1. A plane passing through the origin in R3\R^3R3.
  2. A line passing through the origin in R2\R^2R2.
  3. All of Rn\R^nRn
  4. Image of a linear transformation.
  5. Kernel of a linear transformation
Non-examples of linear subspaces
  1. The unit circle in R2\R^2R2. This is not closed under scalar multiplication or vector addition
  2. The xxx- and yyy-axis of R2\R^2R2. This is closed under scalar multiplication, but not vector additiion.

For the first three examples, we have some intuitive idea of dimension or size. For example, a plane in R3\R^3R3 is 2-dimensional and a line in R2\R^2R2 is 1-dimensional. All of Rn\R^nRn is nnn-dimensional.

Linear subspaces contain the zero vector

Because of the second property, every linear subspace contains 0⃗\vec{0}0. Thus a plane not passing through the origin is not a linear subspace.

It turns out there is a nice way of talking about the dimension of an arbitrary linear subspace using:

Basis of a linear subspace

A set B={v⃗1,…,v⃗m}\mathcal{B}=\{\vec{v}_1,\dots, \vec{v}_m\}B={v1​,…,vm​} contained in a linear subspace VVV is a basis of VVV if

  1. B\mathcal{B}B spans VVV; which is to say that if v⃗\vec{v}v is in VVV, then we can express v⃗\vec{v}v in terms of B\mathcal{B}B:v⃗=c1v⃗1+⋯+cmv⃗m\vec{v} = c_1\vec{v}_1 +\cdots + c_m \vec{v}_mv=c1​v1​+⋯+cm​vm​for some scalars c1,…,cmc_1,\dots, c_mc1​,…,cm​.
  2. B\mathcal{B}B is linearly independent; which is to say that if c1v⃗1+⋯+cmv⃗m=0⃗,c_1\vec{v}_1 +\cdots + c_m \vec{v}_m =\vec{0},c1​v1​+⋯+cm​vm​=0, then cj=0c_j=0cj​=0 for j=1,…,mj=1,\dots,mj=1,…,m. In otherwords, the only way to express 0⃗\vec{0}0 in the span of B\mathcal{B}B is the trivial way.

Exercise: Coordinates in an orthogonal basis

Note that this means that the representation of a vector in an orthogonal basis is the sum of the orthogonal projections of that vector onto each basis vector.

It turns out that there are some nice facts about bases of linear subspaces:

Every linear subspace has a basis
Every basis of a linear subspace has the same number of elements

Using these facts, we can define:

Dimension of a linear subspace

The dimension of a linear subspace VVV, denoted dim⁡(V)\dim(V)dim(V), is the number of vectors in any basis of VVV.

Finding Bases for Image and Kernel of Linear Transformations

We know that the image and kernel of a linear transformation are linear subspaces of their respective spaces. Let's investigate how to find bases for them.

Let AAA be an m×nm\times nm×n matrix. Then we have
ker⁡(A)={x⃗ in Rn∣Ax⃗=0⃗}.\ker(A)= \{\vec{x} \text{ in } \R^n \mid A\vec{x} = \vec{0}\}.ker(A)={x in Rn∣Ax=0}. To find such vectors, it is equivalent to solve rref⁡(A)x⃗=0⃗\operatorname{rref}(A)\vec{x}=\vec{0}rref(A)x=0. Suppose for example that the last two variables, xn−1x_{n-1}xn−1​ and xnx_nxn​, are the only free variables. Then solutions will look something like:
x⃗=(c1,n−1xn−1+c1,nxn⋮cn−2,n−1xn−1+cn−2,nxnxn−1xn)=xn−1(c1,n−1⋮cn−2,n−110)+xn(c1,n⋮cn−2,n01).\vec{x} = \begin{pmatrix} c_{1,n-1}x_{n-1}+c_{1,n} x_n \\ \vdots \\ c_{n-2,n-1}x_{n-1}+c_{n-2,n}x_n\\ x_{n-1}\\ x_n\end{pmatrix} = x_{n-1}\begin{pmatrix}c_{1,n-1}\\ \vdots \\ c_{n-2,n-1}\\ 1 \\ 0\end{pmatrix} + x_n \begin{pmatrix}c_{1,n}\\ \vdots \\ c_{n-2,n}\\ 0 \\ 1\end{pmatrix}.x=​c1,n−1​xn−1​+c1,n​xn​⋮cn−2,n−1​xn−1​+cn−2,n​xn​xn−1​xn​​​=xn−1​​c1,n−1​⋮cn−2,n−1​10​​+xn​​c1,n​⋮cn−2,n​01​​.
From this, we know that span⁡{(c1,n−1⋮cn−2,n−110),(c1,n⋮cn−2,n01)}=ker⁡(A).\operatorname{span}\left\{\begin{pmatrix}c_{1,n-1}\\ \vdots \\ c_{n-2,n-1}\\ 1 \\ 0\end{pmatrix} ,\begin{pmatrix}c_{1,n}\\ \vdots \\ c_{n-2,n}\\ 0 \\ 1\end{pmatrix}\right\}= \ker(A).span⎩⎨⎧​​c1,n−1​⋮cn−2,n−1​10​​,​c1,n​⋮cn−2,n​01​​⎭⎬⎫​=ker(A). Moreover, it is easy to see that these two vectors are linearly independent by looking at the last two entries (the only way to represent the zero vector is to scale each vector by 0). Hence, we have a basis for the kernel.

More generally, we have:

Basis for kernel

A basis for the ker⁡(A)\ker(A)ker(A) can be found by expanding solutions to Ax⃗=0⃗A\vec{x}=\vec{0}Ax=0 in terms of the free variables. The vectors used to express the solutions (the ones scaled by the free variables) form a basis for the kernel.

Finding a basis for the image is a little bit easier. We know by definition of matrix-vector mulitplication that the columns A⃗1,…,A⃗n\vec{A}_1,\dots, \vec{A}_nA1​,…,An​ of AAA span the image:
span⁡{A⃗1,…,A⃗n}=Im⁡(A).\operatorname{span}\{\vec{A}_1,\dots, \vec{A}_n\}= \operatorname{Im}(A).span{A1​,…,An​}=Im(A). Thus, to find a basis, we just need to find some subset of A⃗1,…,A⃗n\vec{A}_1,\dots, \vec{A}_nA1​,…,An​ which still spans and is linearly independent.

If AAA is in row-reduced echelon form, then this is an easy task: we just take the columns with a pivot. These are indeed linearly independent because the only way to linearly represent the zero vector is to scale each vector by 0. Moreover, they span the image because the other columns without pivots are trivially linear combinations of the pivot columns. Thus, removing the non-pivot columns doesn't effect the span.

Because the system Ax⃗=0⃗A\vec{x}=\vec{0}Ax=0 is equivalent to the system rref⁡(A)x⃗=0⃗\operatorname{rref}(A)\vec{x}=\vec{0}rref(A)x=0, the columns of AAA which correspond to pivot columns in rref⁡(A)\operatorname{rref}(A)rref(A) form a basis for the image. More specifically, we have c1A⃗1+⋯+cnA⃗n=0⃗c_1\vec{A}_1+\cdots+ c_n\vec{A}_n=\vec{0}c1​A1​+⋯+cn​An​=0 if and only if c1B⃗1+⋯+cnB⃗n=0⃗c_1\vec{B}_1+ \cdots +c_n\vec{B}_n=\vec{0}c1​B1​+⋯+cn​Bn​=0 where B⃗1,…,B⃗n\vec{B}_1,\dots, \vec{B}_nB1​,…,Bn​ are the columns of rref⁡(A)\operatorname{rref}(A)rref(A). Hence the columns of AAA which correspond to pivot columns are immediately linearly independent via the pivot columns of rref⁡(A)\operatorname{rref}(A)rref(A). Moreover, a column A⃗j\vec{A}_jAj​ is the the span of the previous columns if and only if we can write c1A⃗1+⋯+cj−1A⃗j−1+A⃗j=0⃗.c_1\vec{A}_1+ \cdots + c_{j-1}\vec{A}_{j-1}+\vec{A}_j=\vec{0}.c1​A1​+⋯+cj−1​Aj−1​+Aj​=0. Thus it follows that the columns of AAA corresponding to non-pivot columns of rref⁡(A)\operatorname{rref}(A)rref(A) are in the span of the columns of AAA corresponding to pivots. Therefore, the columns of AAA which correspond to pivots indeed span the image.

Ignoring the details, we have

Basis for image

The columns of AAA which correspond to a pivot column of rref⁡(A)\operatorname{rref}(A)rref(A) form a basis for Im⁡(A)\operatorname{Im}(A)Im(A).

Finding linearly independent subset of arbitrary set while preserving the span.

This method we used to find a basis for the image of a matrix can be used generally to find a linearly independent subset of an arbitrary set of vectors while preserving the span.

More specifically, if we have a set of vectors {v⃗1,…,v⃗m}\{\vec{v}_1,\dots, \vec{v}_m\}{v1​,…,vm​}, we can put them in a matrix A=[v⃗1⋯v⃗m].A=\begin{bmatrix}\vec{v}_1 & \cdots &\vec{v}_m\end{bmatrix}.A=[v1​​⋯​vm​​]. Then a basis for Im⁡(A)\operatorname{Im}(A)Im(A) will be a linearly independent subset of {v⃗1,…,v⃗m}\{\vec{v}_1,\dots, \vec{v}_m\}{v1​,…,vm​} with the same span.

This also gives us a way to get a basis from a collection of vectors which we already know spans a linear subspace.

One thing to notice is that our method to find a basis for the kernel and image shows that
dim⁡(ker⁡(A))=# of free variables\dim (\ker(A)) = \# \text{ of free variables}dim(ker(A))=# of free variablesand
dim⁡(Im⁡(A))=# of pivots=rank⁡(A).\dim (\operatorname{Im}(A)) = \# \text{ of pivots} = \operatorname{rank}(A).dim(Im(A))=# of pivots=rank(A). We also know that the number of free variables plus the number of pivots always equals the number of columns. More generally, we have the following theorem:

Rank-Nullity Theorem

If T:Rn→RmT:\R^n\to \R^mT:Rn→Rm is a linear transformation, then we have
dim⁡(ker⁡(T))+dim⁡(Im⁡(T))=n.\dim(\ker(T)) + \dim(\operatorname{Im}(T))=n.dim(ker(T))+dim(Im(T))=n.

Invertibility

Using Rank-Nullity and otherwise, we have a few more equivalent definitions of invertibility:

Invertibility of a matrix AAA

The following are more equivalent definitions of a n×nn\times nn×n matrix AAA being invertible:

  1. Columns of AAA are linearly independent
  2. Columns of AAA are a spanning set of Rn\R^nRn
  3. Columns of AAA form a basis for Rn\R^nRn.
